## 다음에 다시 만들 때

이 캐러셀은 **날짜가 지나면 그대로는 못 쓴다.** 매주 새로 뽑는다.

```bash
curl -s https://yukjindae-map.wmf34a.workers.dev/api/festivals | jq '.festivals[] | {title, periodStart, periodEnd, region, image}'
```

- 이번 주 날짜에 걸리는 축제만 남기고, 아이 동반 기준(체험·공연·야외 볼거리)으로 5~6곳 추린다.
- 상세 슬라이드는 **개막 가까운 순**으로 배치한다. 기간이 긴 축제는 목록에만 남긴다.
- 사진은 `/images/festivals/...` 경로를 그대로 받아 쓴다(`shots-festival/`).
- 슬라이드는 `slides-festival.html` 의 축제 카드를 갈아끼우면 된다.
- 앱 DB에 없는 축제를 운영진이 주면 사진 자리를 컬러 블록으로 채운다(`.fest__shot--blank`).
  같은 축제를 계속 쓸 거면 앱 축제 DB에 등록해두는 편이 낫다.
- **날짜·장소·프로그램은 API 설명문에 있는 것만 쓴다.** 입장료·주차·예약 여부는
  데이터에 없으므로 확인 전에는 적지 않는다(경복궁 별빛야행 "예매 필요"는 설명문 근거).
