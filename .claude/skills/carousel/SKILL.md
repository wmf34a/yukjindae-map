# 육진대 인스타 캐러셀 만들기

형식·디자인 토큰·함정은 `instagram-carousel/README.md` 에 있다. **먼저 읽고**
그 형식을 그대로 따른다. 이 문서는 작업 순서만 정리한다.

## 1. 무엇을 알릴지 정한다

사용자가 "○○ 기능 알리는 캐러셀" 이라고만 말해도, 슬라이드 하나에 메시지
하나씩 배치해 9장 안쪽으로 끊는다. 기본 뼈대:

표지 → 뭐예요? → 기능 3~5장 → 꼭 확인해주세요 → 댓글 CTA

기능이 애매하면 코드에서 실제 동작을 먼저 확인한다(`public/js/*.js`). 화면에
없는 기능을 슬라이드에 쓰지 않는다.

## 2. 숫자를 API 에서 가져온다

장소·축제·코스·수유실 개수는 매번 바뀐다. `README.md` 의 curl 명령으로 그날
값을 확인해서 쓴다. 추정하거나 지난 캐러셀 숫자를 재사용하지 않는다.

## 3. 앱 화면을 캡처한다

```bash
cd instagram-carousel && node tools/serve.mjs &
BASE=http://localhost:8799 GEO=<lat,lng> node tools/shoot.mjs '[...]' 
```

- `GEO` 는 장소가 몰린 곳으로 잡는다(용산·남산 부근 `37.5340,126.9860` 이 기본).
  빈 지도가 나오면 캐러셀이 초라해 보인다.
- 사용자가 보낸 실기기 스크린샷은 **내 위치가 실제 위치라 그대로 쓰지 않는다.**
  같은 화면을 위 명령으로 다시 찍는다.
- 지도는 `js` 로 `map.setCenter/setZoom` 을 불러 원하는 구도를 잡는다.
- 모달처럼 화면 일부만 크게 보여줄 땐 `clipSel` 로 그 요소만 자른다.

## 4. slides.html 을 고치고 렌더한다

```bash
node tools/render.mjs
cd out && for i in 1 2 3 4 5 6 7 8 9; do
  [ -f s$i.png ] && mv s$i.png $(printf "%02d" $i)-slide.png
done; cd ..
```

슬라이드를 추가하면 뒤 번호를 전부 밀고(`id="sN"`), 주석 번호도 같이 고친다.

## 5. 움직임이 필요하면 녹화한다

정지 화면으로 전달이 안 되는 기능만. `tools/slide/course-video.html` 을 본떠
새 페이지를 만들고:

```bash
node tools/record.mjs http://localhost:8799/_slide/<파일>.html out/NN-slide.mp4 9
```

mp4(업로드용)와 gif(미리보기용)가 같이 나온다.

## 6. 확인하고 넘긴다

렌더한 PNG 를 **직접 열어 본다.** 자주 나는 사고:

- 말풍선 줄바꿈이 깨져 한 글자만 다음 줄로 넘어간다 → 문구를 줄이거나 `<br>` 고정
- 말풍선이 폰 안의 중요한 정보를 가린다 → 위치(`--tl/--br/--foot`)를 옮긴다
- 팝업(설치 유도·튜토리얼)이 캡처에 찍혔다 → `shoot.mjs` 로 다시 찍는다

그다음 캡션(`caption.md` 갱신)과 미리보기 아티팩트까지 만들어 링크를 준다.
아티팩트에서 영상 슬라이드는 **GIF 로 넣는다**(data: mp4 는 재생이 막힌다).

- 미리보기 아티팩트 링크
