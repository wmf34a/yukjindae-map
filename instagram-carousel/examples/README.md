# 실제로 나갔던 캐러셀 (참고용)

문구를 어느 정도 길이로 쓰는지, 슬라이드를 어떻게 나누는지 볼 때 연다.
**사진 파일은 들어 있지 않아서 그대로 렌더하면 이미지 자리가 빈다.** 구조만 참고한다.

| 파일 | 무엇 |
|---|---|
| `slides.html` · `caption.md` | 육진대 맵 오픈 (앱 소개, 영상 슬라이드 포함) |
| `slides-concert.html` · `caption-concert.md` | 유모차 콘서트 모집 (공감→해소→마감 압박 구조) |
| `slides-festival.html` · `caption-festival.md` | 9월 첫째주 축제 (공개 데이터 기반, 개막 순 배치) |
| `slides-demo-lineup.html` | 공연 라인업 표 인포그래픽 |
| `slides-demo-info.html` | 타임라인 · 프로그램 분류 · 코스 순서 세 가지 패턴 |
