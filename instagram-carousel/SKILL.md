# 육진대 인스타 캐러셀 만들기

이 스킬 폴더에 디자인·템플릿·스크립트가 전부 들어 있다. 아래에서 `<스킬폴더>` 는
이 SKILL.md 가 있는 폴더다(보통 `~/.claude/skills/yukjindae-carousel`).

| 파일 | 무엇 |
|---|---|
| `carousel.css` | 디자인 시스템 — 색·글자 크기·컴포넌트 전부 |
| `template.html` | 새 캐러셀 시작점(아빠 운동회 예시로 9장 채워져 있음) |
| `README.md` | 형식·컴포넌트 카탈로그·함정. **작업 전에 읽는다** |
| `tools/render.mjs` | HTML → 슬라이드 PNG |
| `tools/serve.mjs`, `tools/shoot.mjs` | 앱 화면 캡처용(육진대 맵 저장소가 있을 때만) |
| `tools/record.mjs`, `tools/slide/` | 움직이는 슬라이드 녹화 |
| `slides.html`, `caption.md` | 실제로 나갔던 캐러셀과 캡션(2026-09 육진대 맵 오픈) — 본보기 |
| `설치와-사용법.md` | 비개발자용 설치·사용 안내(운영진에게 이 파일을 알려준다) |

## 순서

**주제는 가리지 않는다.** 행사 후기, 모임 모집, 공지, 꿀팁 정리, 장소 추천,
서비스 소개 — 무엇이든 같은 컴포넌트로 만든다. 앱 화면은 필요할 때만 넣는다
(사용자가 "앱 화면 없이" 라고 하거나 사진만 줬으면 넣지 않는다).
사진이 아예 없어도 글 슬라이드(`.checks` `.steps` `.stat` `.quote`)만으로 만들 수 있다 —
다만 표지에 쓸 사진 한 장은 있는 편이 낫다. 없으면 사용자에게 한 장 달라고 한다.

### 1. 소재 확인

- 사진을 받았으면 **Read 로 전부 실제로 본다.** 표지에 깔 12장, 본문에 크게 쓸
  대표컷 3~5장을 고른다. 흔들렸거나 얼굴이 크게 박힌 사진은 뺀다.
- 무엇을 알리는 게시물인지 한 문장으로 정리하고 슬라이드를 나눈다:
  표지 → 뭐예요? → 본문 3~5장 → 꼭 확인해주세요 → 댓글 CTA. **9장 안쪽**(최대 10장).

### 2. 작업 폴더 만들기

사용자가 사진을 둔 곳(또는 새로 만든 폴더)에서 작업한다.

```bash
mkdir -p <작업폴더>/shots
cp <스킬폴더>/carousel.css <스킬폴더>/template.html <작업폴더>/
cd <작업폴더> && mv template.html slides.html      # 사진은 shots/ 로
```

### 3. 슬라이드 작성

`slides.html` 의 예시 문구·사진을 실제 내용으로 바꾼다.
`carousel.css` 에 있는 컴포넌트만 조합한다 — **새 색이나 새 글자 크기를 만들지 않는다.**
어떤 슬라이드에 무엇을 쓰는지는 `README.md` 의 컴포넌트 카탈로그를 본다.

규칙 세 줄:
1. 슬라이드 하나에 메시지 하나. 말풍선은 두 개까지.
2. 강조색은 노랑(`--pop`) 하나.
3. 숫자는 확인된 값만. 모르면 그 슬라이드를 뺀다.

### 4. 렌더

```bash
node <스킬폴더>/tools/render.mjs slides.html out
cd out && i=1; for f in t*.png; do mv "$f" "$(printf '%02d' $i)-slide.png"; i=$((i+1)); done
```

섹션 `id`(t1, t2 …)가 파일 이름이 되므로 순서대로 붙여둔다.

### 5. 눈으로 확인 — 건너뛰지 않는다

렌더한 PNG 를 Read 로 직접 열어 본다. 자주 나는 사고:

- 말풍선 줄바꿈이 깨져 한 글자만 다음 줄로 넘어감 → 문구를 줄이거나 `<br>` 고정
- 말풍선이 사진의 중요한 부분을 가림 → 위치 클래스(`--tl/--br/--foot`) 변경
- 인물 사진이 4:5로 잘려 얼굴이 반만 남음 → `object-position` 조정
- 사진 경로 오타로 빈 칸이 남음

### 6. 캡션

구조: 해시태그 → 오픈 한 줄 → 페인포인트 한 줄 → 📍핵심(불릿 4~5) → 💡참고사항 →
댓글 CTA("'○○' 라고 댓글 남기면 링크 드려요"). 예시는 `caption.md`.

### 7. 넘기기

- `out/01~NN-slide.png` 와 업로드 순서
- 캡션 전문
- (가능하면) 슬라이드를 한 페이지에서 넘겨보는 미리보기 아티팩트 링크.
  영상 슬라이드는 **GIF 로** 넣는다 — 아티팩트 뷰어는 `data:` mp4 재생을 막는다.

## 앱 화면이 들어갈 때

육진대 맵 저장소가 로컬에 있어야 한다.

```bash
APP_PUBLIC=<저장소>/public node <스킬폴더>/tools/serve.mjs &
BASE=http://localhost:8799 GEO=37.5340,126.9860 \
node <스킬폴더>/tools/shoot.mjs '[{"name":"map","path":"/map.html","wait":13000}]' shots
```

- `GEO` 는 "내 위치". 장소가 몰린 곳으로 잡는다(빈 지도는 초라해 보인다).
- 사용자가 보낸 실기기 스크린샷은 내 위치에 실제 위치가 찍혀 있으므로 **그대로 쓰지
  않고** 같은 화면을 다시 찍는다.

## 움직이는 슬라이드

정지 화면으로 전달이 안 되는 것만. `tools/slide/course-video.html` 을 본떠 페이지를
만들고(준비가 끝나면 `window.__ready = true`), 녹화한다.

```bash
node <스킬폴더>/tools/record.mjs <url> out/06-slide.mp4 9
```

mp4(업로드용)와 gif(미리보기용)가 같이 나온다. 인스타는 캐러셀 안 영상 슬라이드를
그대로 받는다. 정지컷 PNG 도 대체용으로 남긴다.

## 사람에게 물어볼 것

- 행사 숫자(참가 인원 등)는 추정하지 말고 묻는다.
- 얼굴이 크게 나온 사진은 게시 동의를 받았는지 확인한다. 공개 게시물이다.
- 댓글 CTA 키워드는 매번 다르다(맵 오픈 때는 '육진대', 운동회면 '운동회'). 정해달라고 한다.
