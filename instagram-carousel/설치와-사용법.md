# 육진대 캐러셀 스킬 — 설치하고 쓰는 법

인스타 캐러셀(넘겨 보는 게시물 이미지)을 클로드한테 만들게 하는 도구입니다.
사진만 주면 육진대 톤에 맞춘 슬라이드 9장과 캡션까지 만들어 줍니다.

개발을 몰라도 됩니다. 아래 순서대로 딱 한 번만 설치하면 그 뒤로는
**"이 사진들로 캐러셀 만들어줘"** 한마디면 됩니다.

---

## 1. 준비물 세 가지 (한 번만)

### ① 크롬 브라우저

이미 있으면 넘어갑니다. 없으면 https://www.google.com/chrome 에서 설치.

### ② Node 22 이상

터미널(맥: `Spotlight`에서 "터미널" 검색)에 아래를 붙여넣고 엔터:

```bash
node -v
```

- `v22.x.x` 이상이 나오면 통과.
- `command not found` 가 나오거나 숫자가 22보다 작으면 https://nodejs.org 에서
  **LTS** 버전을 받아 설치한 뒤 터미널을 껐다 켜고 다시 확인합니다.

### ③ Claude Code

https://claude.com/claude-code 안내대로 설치하고, 터미널에서 `claude` 를 쳐서
한 번 로그인해 둡니다.

---

## 2. 스킬 설치 (복사 한 번)

받은 `yukjindae-carousel` 폴더를 **정해진 자리에 복사**하면 끝입니다.

### 터미널로 하는 법 (권장)

받은 폴더가 다운로드에 있다고 치면:

```bash
mkdir -p ~/.claude/skills
cp -R ~/Downloads/yukjindae-carousel ~/.claude/skills/
```

### 파인더로 하는 법

1. 파인더를 열고 키보드로 `⌘ + ⇧ + G` (커맨드+시프트+G)
2. 나오는 칸에 `~/.claude/skills` 를 치고 엔터
   - "그런 폴더 없다"고 하면 `~/.claude` 로 들어가서 `skills` 폴더를 새로 만듭니다
3. 받은 `yukjindae-carousel` 폴더를 그 안으로 끌어다 놓습니다

이렇게 되면 성공입니다:

```
~/.claude/skills/yukjindae-carousel/SKILL.md
~/.claude/skills/yukjindae-carousel/carousel.css
~/.claude/skills/yukjindae-carousel/template.html
~/.claude/skills/yukjindae-carousel/tools/…
```

### 설치됐는지 확인

터미널에서 `claude` 를 실행하고 `/` 를 쳤을 때 목록에 **carousel** 이 보이면 됩니다.
(안 보이면 클로드를 껐다가 다시 켜 보세요.)

---

## 3. 쓰는 법

### ① 사진을 한 폴더에 모읍니다

예: 바탕화면에 `운동회캐러셀` 폴더를 만들고 사진을 다 넣습니다.
세로로 찍은 사진이 인스타(4:5)에 잘 맞습니다.

### ② 그 폴더에서 클로드를 켭니다

```bash
cd ~/Desktop/운동회캐러셀
claude
```

### ③ 이렇게 말합니다

> 이 폴더 사진들로 아빠 운동회 캐러셀 만들어줘. 60가족 참가했고, 마지막에 '운동회'라고
> 댓글 남기면 다음 모임 신청 링크 준다고 해줘.

클로드가 사진을 보고 슬라이드를 짠 다음 이미지로 뽑아 줍니다.
결과는 그 폴더 안 `out/` 에 `01-slide.png`, `02-slide.png` … 순서대로 생깁니다.

### ④ 고칠 게 있으면 그냥 말합니다

> 3번 문구를 "출발선 앞에서 제일 긴장한 건 아빠였습니다"로 바꿔줘
> 표지 사진을 단체 사진으로 바꿔줘
> 5번은 빼줘

### ⑤ 인스타에 올립니다

`out/` 안의 이미지를 **번호 순서대로** 올리고, 같이 만들어 준 캡션을 붙여넣습니다.

---

## 3-1. 어떻게 나오는지 먼저 보고 싶다면

**`미리보기/`** 폴더 안 파일을 더블클릭하면 브라우저에서 바로 열립니다.

| 파일 | 무엇 |
|---|---|
| `미리보기/템플릿.html` | 슬라이드 9종이 어떤 모양인지 (사진 자리는 회색 판) |
| `미리보기/A-클린.html` | 톤 A — 밝은 회백 + 남색 |
| `미리보기/B-써니.html` | 톤 B — 크림 종이 + 둥근 글씨 |
| `미리보기/C-나이트.html` | 톤 C — 짙은 남색 + 형광 |
| `미리보기/예제-축제.html` | 실제로 나간 축제 캐러셀 |
| `미리보기/예제-콘서트.html` | 실제로 나간 유모차 콘서트 모집 캐러셀 |

이 파일들은 디자인과 사진이 파일 안에 들어 있어서 **다른 폴더로 옮겨도, 메일로 보내도
그대로 열립니다.**

> 참고: `template.html`, `themes/`, `examples/` 안의 파일들은 같은 폴더의 `carousel.css` 를
> 함께 읽습니다. 그 파일만 따로 떼어 다른 곳에서 열면 글자만 보이니, 확인은 `미리보기/`
> 폴더로 하세요.

## 3-2. 톤 바꾸기 (테마 A · B · C)

같은 내용으로 세 가지 톤이 준비돼 있습니다. 말로 고르시면 됩니다.

| 테마 | 느낌 | 어울리는 소식 |
|---|---|---|
| **A 클린** | 밝은 회백 + 남색 (기본) | 정보 전달·공지 |
| **B 써니** | 크림 종이 + 둥근 글씨 | 아이 행사·모집·후기 |
| **C 나이트** | 짙은 남색 + 형광 | 야간 축제·불꽃놀이·공연 |

> 써니 테마로 만들어줘
> 표지는 나이트로 하고 나머지는 써니로 뽑아줘
> 세 가지 다 만들어서 비교하게 해줘

어떤 게 나은지 모르겠으면 **"세 가지 다 뽑아줘"** 하시면 나란히 보여드립니다.
폴더 안 `themes/preview-a.html`, `preview-b.html`, `preview-c.html` 을 더블클릭해도
각 톤이 어떤지 미리 볼 수 있습니다.

## 4. 알아둘 것

- **최대 10장**입니다. 보통 9장으로 맞춥니다.
- **얼굴이 크게 나온 사진은 당사자 동의를 받은 것만** 넣습니다. 공개 게시물입니다.
- **숫자는 확인된 것만** 알려주세요. 참가 인원 같은 걸 모르면 그 슬라이드는 뺍니다.
- 디자인(색·글자)은 이미 육진대 톤으로 맞춰져 있습니다. 바꾸고 싶으면 테마로 바꾸세요.
- 축제·행사 정보로 만들 때는 **공공데이터(한국관광공사)에서 사진과 정보를 받아옵니다.**
  블로그나 뉴스 기사 사진은 저작권 때문에 쓰지 않습니다.
- 앱 화면이 들어가는 캐러셀은 육진대 맵 저장소가 컴퓨터에 있어야 합니다.
  없으면 앱 화면 없이 사진만으로 만들면 됩니다.

## 5. 잘 안 될 때

| 증상 | 해볼 것 |
|---|---|
| `/` 목록에 carousel 이 없다 | 폴더 위치가 `~/.claude/skills/yukjindae-carousel/SKILL.md` 인지 확인 → 클로드 재시작 |
| 이미지가 안 만들어진다 | 터미널에서 `node -v` 가 22 이상인지, 크롬이 깔려 있는지 확인 |
| 글씨가 이상하게 벌어져 나온다 | 인터넷 연결 확인(글꼴을 인터넷에서 받아옵니다) 후 다시 만들어 달라고 하기 |
| 사진이 안 보이고 빈 칸 | 사진 파일 이름에 오타가 없는지, 사진이 그 폴더에 있는지 확인 |

그래도 안 되면 만든 사람(개발팀)에게 터미널에 나온 빨간 글씨를 그대로 보내주세요.
