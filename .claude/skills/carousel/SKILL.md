# 육진대 인스타 캐러셀

이 저장소에서는 `instagram-carousel/` 폴더가 스킬 본체다.

1. `instagram-carousel/SKILL.md` 를 읽고 그대로 따른다. `<스킬폴더>` 는
   `instagram-carousel` 이다.
2. 형식·컴포넌트 카탈로그가 필요하면 `instagram-carousel/README.md`.
3. 작업 폴더를 따로 만들 필요 없이 `instagram-carousel/` 안에서 작업해도 된다
   (사진은 `shots/`, 결과는 `out-<주제>/`).

운영진에게 폴더째 넘길 때는 `instagram-carousel/설치와-사용법.md` 를 함께 준다.
