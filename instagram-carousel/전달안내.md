# 운영진 전달 안내 (보내는 사람용)

캐러셀 도구를 다른 운영진에게 넘길 때 이 문서대로 하면 된다.
받는 사람이 읽을 문서는 패키지 안 `설치와-사용법.md` 다.

## 무엇을 보내나

**`yukjindae-carousel-skill.zip`** (약 120KB) 하나만 보낸다.
압축을 풀면 **`yukjindae-carousel`** 폴더가 나온다.

> **폴더 이름은 `yukjindae-carousel` 그대로 둬야 한다.**
> 클로드가 이 이름으로 스킬을 찾는다. 바꾸면 인식이 안 된다.

```
yukjindae-carousel/          ← 이 폴더째로 ~/.claude/skills/ 안에 넣는다
  SKILL.md                   클로드가 읽는 작업 지시
  설치와-사용법.md            사람이 읽는 안내 ← 받는 사람은 이것부터
  carousel.css               디자인(색·글자·컴포넌트)
  themes/                    테마 3종(클린·써니·나이트) + 톤 미리보기 3장
  template.html              새 캐러셀 시작점(아빠 운동회 예시로 채워둠)
  템플릿-미리보기.html         더블클릭하면 바로 열리는 단독 파일
  examples/                  실제로 나간 캐러셀 세 편 + 인포그래픽 패턴
  tools/                     렌더·캡처·녹화 스크립트
  shots/                     곰돌이 로고 + 자리표시 이미지
```

압축 파일은 이 저장소에서 다시 만들 수 있다:

```bash
cd instagram-carousel
PKG=/tmp/yukjindae-carousel && rm -rf "$PKG" && mkdir -p "$PKG/shots" "$PKG/tools"
mkdir -p "$PKG/themes" "$PKG/examples" "$PKG/shots/placeholder"
cp SKILL.md README.md 설치와-사용법.md carousel.css template.html 템플릿-미리보기.html "$PKG/"
cp -R tools/* "$PKG/tools/"
cp themes/*.css themes/preview-*.html "$PKG/themes/"
cp examples/* "$PKG/examples/"
cp shots/character-logo-600.png shots/main-logo.svg "$PKG/shots/"
cp shots/placeholder/*.svg "$PKG/shots/placeholder/"
cd /tmp && zip -rq ~/Desktop/yukjindae-carousel-skill.zip yukjindae-carousel -x "*.DS_Store"
```

`out/` 과 `shots/` 의 사진 원본은 넣지 않는다(23MB라 무겁고, 받는 사람은 자기 사진을 쓴다).

## 같이 보낼 메시지

> 캐러셀 만드는 도구 보내드려요. 압축 풀면 나오는 **`yukjindae-carousel` 폴더를
> 이름 그대로** `~/.claude/skills/` 안에 넣으면 설치 끝이에요.
> 자세한 건 폴더 안 **설치와-사용법.md** 에 순서대로 적어놨습니다.
>
> 설치되면 사진 모아둔 폴더에서 클로드를 켜고
> "이 사진들로 ○○ 캐러셀 만들어줘" 하시면 됩니다.
> 디자인은 육진대 톤으로 이미 맞춰져 있어요.
>
> 두 가지만 지켜주세요 — 얼굴 크게 나온 사진은 동의받은 것만,
> 참가 인원 같은 숫자는 확인된 것만요.

## 받는 사람이 하게 되는 일 (요약)

| 단계 | 내용 |
|---|---|
| 준비물 | Chrome · Node 22 이상 · Claude Code (한 번만) |
| 설치 | `yukjindae-carousel` 폴더를 `~/.claude/skills/` 로 복사 |
| 확인 | 터미널에서 `claude` → `/` 입력 시 목록에 스킬이 보이면 성공 |
| 사용 | 사진 폴더에서 `claude` 실행 → "이 사진들로 캐러셀 만들어줘" |
| 결과 | 그 폴더 `out/` 안에 `01-slide.png` … 순서대로 + 캡션 |
| 게시 | 번호 순서대로 인스타에 올리고 캡션 붙여넣기 |

## 저장소를 볼 수 있는 사람이면

압축을 보낼 필요 없다. `yukjindae-map` 을 clone 하고 `instagram-carousel/` 에서
작업하면 된다 — 프로젝트 스킬(`.claude/skills/carousel/`)이 같이 딸려온다.

## 물어올 만한 것

- **"디자인 좀 바꿔도 되나요?"** — 테마 세 개(클린·써니·나이트) 중에 고르라고 안내한다.
  말로 "써니 테마로 만들어줘" 하면 된다. 그래도 부족하면 `carousel.css` 의 `:root`
  값만 고치게 한다(그래야 전체가 같이 바뀐다).
- **"축제 정보로도 되나요?"** — 된다. 앱 축제 API와 한국관광공사 TourAPI에서 사진·정보를
  받아 만든다. 블로그·뉴스 사진은 저작권 때문에 쓰지 않는다.
- **"몇 장까지 되나요?"** — 인스타 상한 10장. 보통 9장.
- **"앱 화면도 넣고 싶어요"** — 육진대 맵 저장소가 그 컴퓨터에 있어야 한다.
  없으면 사진만으로 만든다.
- **"영상도 되나요?"** — 된다(`tools/record.mjs`). 다만 앱 화면을 움직여 찍는 용도라
  일반 행사 캐러셀에는 거의 쓸 일이 없다.
